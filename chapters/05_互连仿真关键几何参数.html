05 · 互连仿真的关键几何参数：哪些结构尺寸决定电流密度、温度与应力分布

0. 一句话结论

几何参数不是画图细节，而是模型的输入变量。

  • 电流密度/电迁移 ← bump 直径、焊料高度（standoff height）、焊料帽厚度、Cu 柱高径比、节距、IMC 初始厚度；
  • 温度场 ← bump 高度与数量（热路径/并行热通道）、Cu 柱比例、underfill 热导率、die 厚度；
  • 应力/翘曲/疲劳 ← bump 高度/直径/节距、芯片与基板厚度、TSV 直径/深宽比/间距、叠层对称性；
  • 混合键合界面应力与良率 ← pad 尺寸/间距、Cu 密度与图案、CMP dishing/recess、对位误差。

2. 电流密度与电迁移：哪些尺寸在“管”J 分布

2.1 文献明确出现的几何量

  1. 焊料高度（standoff height）与焊料体积：“厚 Cu 柱 + 浅焊料（thick Cu column + shallow solder）”被专门研究，说明铜柱高度与焊料层厚度的比例是 EM 的关键结构变量：改变电流路径与焦耳热分布 [S3]；不同焊料直径下 Cu-Sn IMC 占比不同，导致 bump 电阻随 IMC 形成而变化——直径是 IMC 占比的杠杆 [S7]。
  2. bump 直径与节距（尺寸效应）：细间距 Cu 微凸点的结构差异直接影响电学可靠性 [S4]；Sn3.5Ag 倒装焊点的尺寸与几何影响电迁移行为 [S5]；细间距 Cu pillar 的不同 bump 结构对 EM 性能有可测影响 [S1]；焊料 bump 与 Cu pillar 的 EM、熔断与热机械性能被直接对比 [S2]。
  3. Cu 柱高度/直径、Ni 阻挡层、焊料帽厚度：Cu pillar/Ni/Sn-Ag/Cu 微凸点在双向电流下的界面反应与 EM 失效表明，Ni 层、焊料帽与柱体尺寸共同决定失效位置与寿命 [S8]；焊料 vs 铜互连的 EM 性能指标有行业级对比 [S32]；Sn 在 Ni/Cu 表面的表面扩散是微凸点 EM 的新失效路径——界面/表面几何进入建模 [S9]。
  4. 电流入口与 IMC 界面（电流拥挤发生地）：电流拥挤集中在焊料入口与 IMC 界面，局部 J 远高于平均 J；UBM/布线开口尺寸、IMC 初始厚度与形貌是 J 分布的直接输入 [S8][S9][S32]。

2.2 进入神经网络模型的建议

  • 输入几何：bump 直径 d、焊料高度 h、焊料帽厚度、Cu 柱高度/直径（或高径比）、节距、UBM 开口、IMC 初始厚度；
  • 输出物理量：J 分布（含电流拥挤因子）、焦耳热、EM 寿命（Black 型 寿命 ∝ J⁻ⁿ · exp(Ea/kT)，n 与 Ea 需用文献标定，IRDS 2024 MET 有失效机理与指标框架 [S31]）；
  • 网格/子域提示：IMC 界面与入口的局部 J 梯度大，应与项目现有“边缘/界面子域细化”思路一致（参考 MDPI 子模型范式 [S19]）。

3. 温度场：哪些尺寸在“管”T 分布

  1. bump 高度 = 热路径长度；bump 数量/直径 = 并行热通道：bump 与 underfill 对倒装封装热行为有可测影响 [S10][S11]。
  2. Cu 柱比例：Cu 的热导率远高于焊料，Cu 柱占比越高、热路径越“铜”，封装热阻越低（与 EM/热机械性能对比同源 [S2]）。
  3. underfill/塑封热导率：有无 underfill、不同 underfill 材料会改变结温与温度分布 [S10][S11]；薄 die 混合键合堆叠的散热瓶颈来自极薄的硅与高密度互连 [S30]。
  4. die/基板厚度与功率图：温度场由功率密度 + 各层厚度 + 材料热导共同决定（与知识库中 PI-ONet、HBM 结温代理等工作同路）。

3.1 进入神经网络模型的建议

  • 输入几何/材料：bump 高度、直径与阵列密度、Cu 柱比例、underfill/EMC 热导率、die/基板厚度、功率分布；
  • 输出物理量：稳态/瞬态温度场、热点位置与结温。

4. 应力/翘曲/疲劳：哪些尺寸在“管”σ 与寿命

  1. bump 几何（直径/高度/节距）是疲劳寿命的一阶因子：田口方法研究表明 bump 几何对倒装封装疲劳寿命影响显著 [S12]；bump 节距与 underfill 变化共同决定热疲劳寿命 [S13]；standoff 高度变化直接改变高温疲劳寿命 [S14]；FEA + RSM 参数化研究表明互连设计是热应力/应变分析的核心变量 [S15]。
  2. Cu pillar 与低 k 介质层：Cu pillar bump 用于 ultra-low-k 芯片时，凸点下方局部应力传入介质层 [S17]；40 μm 节距 Cu-Pillar/SnAg 微凸点有专门可靠性研究 [S16]。
  3. TSV 几何（直径/深宽比/间距/布局）：TSV 热应力改变周围载流子迁移率并形成 keep-out zone（KOZ），KOZ 大小由 TSV 几何决定 [S20]；周期性 TSV 阵列应力有解析近似解——直径、间距、布局决定应力场形态 [S33]；Cu CTE ≈ 17 ppm/K、Si ≈ 2.6 ppm/K 是热应力根源 [S34]；TSV 中介层温度循环子模型仿真把全局-局部应力分开算 [S19]。
  4. 大面积 2.5D 模塑封装翘曲：叠层厚度、芯片/中介层/基板尺寸与对称性 [S18]。

4.1 进入神经网络模型的建议

  • 输入几何：bump 高度/直径/节距、芯片/中介层/基板/塑封各层厚度、TSV 直径/深宽比/间距/布局、叠层对称性；
  • 输出物理量：应力场（含界面应力）、翘曲形貌、疲劳寿命判据（应变能密度/塑性应变等）；
  • 直接证据：TSV-INet 已把“任意分布 TSV 布局”作为网络输入来预测晶圆翘曲 [S27]，说明几何布局作为输入特征可行；WarpagePINN 走热翘曲 PINN 路线 [S28]。

5. 混合键合特有几何参数

  1. pad 尺寸与节距：演示/量产已到 300 nm 节距（50 nm 对位）与 1 μm 节距（<300 nm 对位）[S25][S26]；Intel Foveros Direct 给出 ≤10 μm、>1 万连接/mm² 的量产指标 [S29]。
  2. Cu 密度与图案：1 μm 节距混合键合 FEM 表明 Cu 密度影响键合面积与界面应力 [S21]；Cu pad 尺寸影响 Cu 在退火中的热膨胀行为 [S23]；Cu pad 非弹性变形下的鲁棒设计是可靠性建模对象 [S22]。
  3. CMP dishing / Cu recess 与对位误差：纳米级平整度与对位决定界面接触质量与良率；YAP/YAP+ 把 pad 布局作为良率模型输入 [S24]。
  4. 晶圆/芯片厚度与翘曲：混合键合对超薄 die 的翘曲极敏感（C2W 翘曲工程文献见知识库 TSV 基础笔记 4.5 节）。

5.1 进入神经网络模型的建议

  • 输入几何：pad 尺寸/间距、Cu 密度与图案、dishing/recess、对位误差、退火温度、die/晶圆厚度；
  • 输出物理量：界面应力、键合面积/良率、热膨胀与翘曲。

6. 与神经网络建模的对应（初步建议，待与师兄确认）

模型子域（现有四分）建议增加的几何输入对应物理场输出
中介层块（bulk）各层厚度、材料参数、TSV 平均密度全局温度场、翘曲
中介层边缘（edge）边缘几何、与基板/塑封边界边缘高梯度应力
TSV 实体（body）TSV 直径、深宽比、侧壁角、间距局部应力集中
TSV 边缘（liner/interface）阻挡层/绝缘层厚度、Cu 突起界面应力、失效萌生
互连层（建议新增或并入边界）bump/pillar/pad 直径、高度、节距、焊料帽厚度、IMC 厚度J、T、σ、疲劳寿命

TSV-INet 的“任意布局 → 翘曲”输入方式 [S27] 与 YAP+ 的“pad 布局 → 良率”输入方式 [S24] 说明：几何布局直接作为网络输入是本领域已有做法。
