0. 一句话结论

填充仿真的几何输入，核心是“缝隙几何 + 芯片/模腔几何 + 材料填料几何”。

  • 流动与空洞 ← 芯片-载体间隙高度、bump 节距与阵列方向、芯片尺寸/长宽比、填料粒径 vs 间隙、模腔厚度与排气；
  • 温度场与固化应力 ← die/基板/模帽厚度、温度历史、固化收缩；
  • 翘曲与界面应力 ← die 厚度、模帽厚度、叠层对称性、fillet 几何；
  • 缺陷（die shift / 分层 / 焊料挤出）← 芯片厚度与面积、流动方向、界面几何、bump 节距与焊料体积、模塑压力。

2. 流动与填充：哪些尺寸在“管”流动前沿与空洞

2.1 文献明确出现的几何量

  1. 芯片-载体间隙高度（gap / standoff）：毛细底填靠间隙内的毛细力推进，缝隙越窄、流动越慢、填充时间越长，越容易形成流动空洞；窄间隙填充能力是材料与结构联合指标 [S12][S14]。
  2. bump 节距、阵列与方向：倒装 BGA 阵列结构（节距、排列方式）直接影响毛细底填流动路径 [S1]；高密度 flip-chip 的微尺度底填动力学与空洞形成由 bump 阵列几何决定 [S2]；多尺度建模可预测流动与空洞 [S3]。
  3. 芯片尺寸与长宽比：流动长度随芯片尺寸增大而增大，大面积细间距芯片的填充时间与空洞风险显著上升（CUF 在 chiplet 场景吃力的原因）[S12][S14]。
  4. 填料粒径与含量：填料粒径相对间隙过大 → 团聚/架桥/阻塞；填料含量越高黏度越大、CTE 越低——流动性与低翘曲互相打架 [S12][S13]。
  5. 模腔厚度、排气与分配位置（模塑侧）：压缩模塑的模腔设计（厚度、vent/排气、EMC 分配量与位置）决定空气裹入与填充完整性 [S15][S16]；“一芯片 + 多 decaps”晶圆级压缩模塑有专门的工艺-结构优化研究 [S24]。
  6. MUF 的窄缝空洞风险：FC-POP 模塑底填的空洞风险已用参数化研究（两相、可压缩流/多孔介质模型）仿真预测 [S5]；20 μm 以下细间距 CoW 的两种模塑方法对比给出工艺窗口 [S4]。

2.2 进入神经网络模型的建议

  • 输入几何/材料：间隙高度、bump 节距/阵列/方向、芯片长宽尺寸、填料粒径与含量、模腔厚度、排气与分配位置、黏度-温度曲线；
  • 输出物理量：流动前沿位置与时间、压力场、空洞率与空洞位置；
  • 提示：流动问题本质是“几何约束下的两相流”，先做参数化 CFD/FEM 数据再训练代理模型（与 [S5] 路线一致）。

3. 固化与热：哪些尺寸在“管”温度场与残余应力

  1. 各层厚度（die / 基板 / 模帽）：决定热阻路径、热容与翘曲刚度；模塑料体积与厚度直接改变 CoW 翘曲趋势 [S10][S11]。
  2. 固化/回流温度历史（150–260 ℃ → 室温）：冷却阶段各层收缩量不同，残余应力在冷却时“冻结” [S11][S13]。
  3. 固化收缩率：EMC/底填的化学固化收缩叠加在热收缩上，增大残余应力与翘曲 [S13]。
  4. 材料热导率与功率密度：底填/塑封把热从芯片导出，材料热导与功率图共同决定结温与热点（2.5D/3D 散热综述 [S20]；bump/underfill 热行为实验 [S10h]）。

3.1 进入神经网络模型的建议

  • 输入：各层厚度、固化/冷却温度曲线、固化收缩率、材料 CTE(T)/热导率、功率图；
  • 输出：温度场、固化度、残余应力场。

4. 应力/翘曲：哪些尺寸在“管”翘曲与界面应力

  1. die 厚度：统一/匹配 die 厚度是控制单元翘曲的手段 [S9]。
  2. 模帽厚度与塑封料体积：封装几何（模帽、基板、芯片厚度与位置）直接用于翘曲与 die 应力控制 [S10]；模塑 2.5D chiplet 的翘曲与应力分析把叠层作为核心变量 [S11]；存储-计算 chiplet 的 2.5D 翘曲优化同样落在叠层参数上 [S18]。
  3. 叠层对称性：对称叠层让上下收缩趋势互相抵消，是低翘曲设计的常规手段 [S10][S13]。
  4. 间隙高度与 fillet 几何：底填 fillet 参与界面力分配与分层风险 [S17]；回流过程中 fillet 力与 bump 几何耦合（无流动底填场景）[S21]。

4.1 进入神经网络模型的建议

  • 输入几何：die/基板/模帽厚度、芯片位置与对称性、间隙高度、fillet 尺寸（高度/润湿角）、材料 CTE/模量/Tg；
  • 输出物理量：翘曲形貌、界面应力、疲劳寿命判据。
